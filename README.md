# Simulare Cake Vending Machine & Sistem de Gestiune (C++)

O aplicație consolă creată în C++ ce simulează funcționarea unui automat de prăjituri și gestionează stocul de produse.

## Tehnologii și Concepte Utilizate:
* **C++ (STL):** Structuri de date, vectori, string-uri.
* **Programare Orientată pe Obiecte (POO):** Encapsulare, Moștenire, Polimorfism, Abstragere.
* **Management Fișiere:** Citire și scriere în fișiere externe pentru persistența datelor.

## Funcționalități:
1. Meniu interactiv pentru utilizatori (selectare produse).
2. Meniu de administrare pentru gestionarea stocului și vizualizarea tranzacțiilor.
3. Salvarea automată a stocurilor și câștigurilor în fișiere text externe.

## Cum se rulează:
Deschide soluția în Visual Studio (`.sln`) și apasă `F5` sau compilează fișierele `.cpp` folosind orice compilator C++ (g++, MinGW).
